# INSPIRED CREATION — Handcrafted Wooden Gifts & Artisan Decor

A modern, responsive e-commerce web platform for **INSPIRED CREATION**, dedicated to handcrafted wooden gifts, personalized keepsake boxes, executive desk organizers, minimalist photo frames, and artisan wooden decor.

## Features Included
- **Responsive Artisan Design**: Optimized for mobile phones, tablets, and desktop computers.
- **Product Catalog & Filtering**: Filter by category (Keepsake Boxes, Desk & Office, Photo Frames, Lamps & Lighting, Wall Clocks) and live search.
- **Currency Switcher**: Toggle between Bangladeshi Taka (৳ BDT) and US Dollar ($ USD).
- **Interactive Quick View**: Inspect wood specifications, dimensions, and craftsmanship details.
- **Live Laser Engraving Studio**: Real-time simulation of custom names, wedding/anniversary dates, and font styles.
- **Shopping Cart & Checkout Flow**: Slide-out cart drawer, dynamic delivery fee calculation for Bangladesh (Inside/Outside Dhaka), and order confirmation with tracking IDs.
- **Wishlist System**: Save favorite items locally.
- **Inquiry Form & Social Links**: Direct WhatsApp, hotline, and contact integration.

## How to Make It Live on GitHub Pages (Free Hosting)
1. In your GitHub repository (`INSPIREDCREATION-webside`), make sure `index.html` is uploaded in the main branch.
2. Go to **Settings** > **Pages** (on the left sidebar).
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your website will be live at:
   `https://tanvir89-ctrl.github.io/INSPIREDCREATION-webside/`
